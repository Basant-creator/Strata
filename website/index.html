Get started

Your agent forgets why. Strata remembers.

Strata gives your agent the why behind your code, with every statement labelled by how far it can be trusted.

Get started View on GitHub

When you build with an AI agent, the code survives and the reasoning disappears. Why one approach was chosen. Which ones failed. What a change must keep. The next session starts from zero.

Three sources, one context pack.

Strata keeps a small memory inside your repository. When you give your agent a task, it builds a pack about the code that task touches.

Everything lives in .strata/ in your repository. No server and no cloud.

  1. Git history

    Which commits changed which files, and what each change replaced.

    decided in 91aefdd (ignore duplicate webhook deliveries)
  + if (seen.has(id)) return false;
  + seen.add(id);

  2. Code index

    The functions and exports in each file, which files import which, and where things are called.

    src/webhooks/handler.ts:2  export function handleWebhook(id: string): boolean {
used at:  src/webhooks/router.ts:2  handleWebhook

  3. Records

    Short notes on intent, failed attempts and constraints. You or an agent write them, or Strata derives them from a session.

    strata record --intent "Ignore duplicate webhook deliveries" \
  --attempt "Database row lock:failed:too slow under load" \
  --constraint "handleWebhook must stay idempotent"

Every statement says how far to trust it.

This is what an agent receives. Pick a label to see which lines carry it.

Strata also checks records against git. If a record says a commit changed a file and git shows it did not, the record is marked CONTRADICTED by git.

Same question, less digging.

Without Strata

  • The agent searches the code for the area.
  • It reads git log, then opens old diffs one by one.
  • It works out the decision again from scratch.
  • It may repeat a mistake that was already made and fixed.

The answer arrives, after the same archaeology every session.

With Strata

  • The pack arrives before the agent's first turn.
  • The commits that shaped the file come with their diffs.
  • Constraints and failed attempts are already stated.
  • Each past decision says whether it still holds.

The same answer, with less searching to reach it.

What Strata does not do.

Strata states what it does not know. So does this page.

It covers TypeScript and JavaScript.
Python, Go, Rust and most other languages are not understood yet. A request about such a file gets no pack.
It does not make answers more correct.
Without Strata, agents reached the same answers by reading git and the code. Strata cuts the digging.
Every prompt costs about 2,400 tokens.
Even a trivial question gets a pack through the Claude Code hook, so simple questions cost slightly more.
Records are claims.
Strata checks one kind of claim against git and labels the rest DECLARED. It cannot remember what nobody wrote down.

Set up in four commands.

You need Node.js 22.13 or newer and a git repository with at least one commit.

  1. Clonegit clone https://github.com/Basant-creator/Strata.git
  2. Buildcd Strata && npm install && npm run build
  3. Linknpm link
  4. Set upstrata setup claude-code antigravity

Run the last command inside your own project. It indexes the repository, writes the readable docs and wires each editor you name.

How it reaches your agent

Claude Code
A prompt hook adds a context pack to every prompt, before the agent starts.
Antigravity
An always-on rule points the agent at the project memory each session.
Any other agent
Plain Markdown docs in your repository, or Strata's MCP server.
